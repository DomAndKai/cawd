# Roomie-Landing
Landing page, privacy policy, terms, and public info for Roomie

## Local preview

This is a static GitHub Pages-ready site. Preview it locally from the repository root:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Publish the repository with GitHub Pages using the repository root as the Pages source. The main pages are:

- `index.html`
- `privacy.html`
